# DEV. SAHIL / NETWORKING STUDIO
### The Complete Cybersecurity Networking Foundation & Interactive Laboratory

An ultra-rich, interactive live-motion educational platform engineered by **Dev. Sahil** for cybersecurity students, ethical hackers, and network engineers. Designed from ground zero so that anyone with zero prior knowledge can master every critical networking concept.

---

## 🌟 Key New Features & Visual Enhancements

1. **Brand Identity:** Rebranded across the entire studio to **Dev. Sahil / Networking Studio**.
2. **One Connected Learning Path (5-Stage Roadmap):**
   - Direct interactive roadmap banner on the overview matching the video curriculum:
     1. *Stage 1: Build the map* (Chapters 1 to 6) — Networks, layers, devices
     2. *Stage 2: Find the destination* (Chapters 7 to 11) — MAC, IP, subnetting, routes
     3. *Stage 3: Make a connection* (Chapters 12 to 15) — Ports, TCP, UDP, TLS
     4. *Stage 4: Speak the protocols* (Chapters 16 to 20) — DNS, HTTP, mail, access
     5. *Stage 5: Observe and defend* (Chapters 21 to 23) — Policy, tunnels, Wireshark
3. **Interactive Pictorial Network Lab (Full Width):**
   - **Choose what you use:** Phone, Laptop, Printer, Smart TV, Tablet
   - **Test Scenarios:** Everything is connected, Internet cable unplugged, Wi-Fi turned off, Guest Wi-Fi isolation enabled
   - **Visual Diagrams:** Home network boundary with central Wi-Fi box, wired Ethernet cables, wireless Wi-Fi radio links, and external cloud Internet connection.
4. **Live Port & Bandwidth Dynamic Experimenter:**
   - **Device & Port Slider (1 to 50):** Watch available bandwidth split, channel congestion rise, and ping latency climb live!
   - **Bandwidth Slider (10 to 1000 Mbps):** Switch from slow DSL to Gigabit Fiber.
   - **Port Selector (80 HTTP, 443 HTTPS, 22 SSH, 53 DNS, 21 FTP, 3389 RDP):** See encryption vs cleartext sniffing vulnerabilities updated in real time.
5. **Full Beginner-Friendly Educational Content ("THE IDEA"):**
   - Concepts explained in plain language and intuitive analogies for complete beginners.
   - Structured 3-card breakdowns: **Familiar action**, **Same foundation**, **Security question**.
   - Red Team (Offensive Attack) vs Blue Team (Defensive Protection) insight on every single screen.
6. **Non-Blocking Dedicated Cyber Terminal & Wireshark Studios:**
   - Terminal moved from a cramped side pane into a dedicated, full-featured Cyber Shell running `ping`, `traceroute`, `arp -a`, `netstat -ano`, `dig`, `curl -v`, and `nmap -sS`.
   - Authentic 3-pane Wireshark Dissector with real captured PCAPs, display filtering, and TCP stream reassembly.
7. **Exam-Ready Questions with Detailed Explanations:**
   - Interactive multiple-choice questions with step-by-step example reasoning aligned with CompTIA Network+, Security+, and CEH certifications.

## 🚀 How to Launch

### Option 1: One-Click Launch (Windows)
Double-click `run.bat` in this folder. It automatically starts the local web server and opens your browser at `http://localhost:8000`.

### Option 2: Python Command Line
```bash
python -m http.server 8000
```
Open `http://localhost:8000` in any browser.

### Option 3: Direct Browser Open
Double-click `index.html` to open directly in Chrome, Firefox, Edge, or Brave (100% offline ready).

## ⌨️ Studio Controls
- **`/`** : Instant Global Search (fuzzy-searches all 23 chapters & 114 screens)
- **`F`** : Focus Mode (collapses sidebar into clean 16:9 widescreen presentation mode)
- **`←` / `→`** : Step backward / forward through chapter lesson screens
- **`Pause Motion`** : Pause or resume live background animations and packet pulses
- **`ESC`** : Close active dialogs and modals
